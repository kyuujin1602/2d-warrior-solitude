# ** 2D Adventure Game Project - Warrior's Solitude **

This is a personal project of game development created for my learning of Unity through an online course.

Some features of the project:
- Attacks and combos.
- Spells, skill system, leveling up skills.
- Equipments, materials and items.
- Inventory, storage systems.

The project is not finished.

Course reference: Ultimate Guide To Creating an RPG Game in Unity 6 by Unity Alex Dev
